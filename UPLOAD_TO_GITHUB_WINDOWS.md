# One-Touch GitHub Upload — Windows

The extracted folder is already the repository root. Do not create another folder inside it.

## GitHub Desktop

1. Extract `SQL-Server-Observability-and-DBA-SRE-Toolkit-GitHub-Ready.zip`.
2. Open **GitHub Desktop**.
3. Select **File → Add local repository**.
4. Choose the extracted `SQL-Server-Observability-and-DBA-SRE-Toolkit` folder.
5. If GitHub Desktop says the folder is not a repository, select **create a repository here**.
6. Confirm the repository name and use the `main` branch.
7. Commit all files with: `Publish SQL Server Observability and DBA SRE Toolkit v1`
8. Select **Publish repository**.
9. Publish to `https://github.com/lachungo/SQL-Server-Observability-and-DBA-SRE-Toolkit`.
10. Open **Actions** on GitHub. **Package integrity** should finish with a green check mark.
